# UX 디자인(UI/UX)과 온보딩

![](../../raw/mobilefreetoplay-bible/media.mobilefreetoplay.com/wp-content/uploads/2017/12/user-experience-design-ui-ux-onboarding-2.png)

플레이어가 제품과 어떻게 상호작용할지 고민하는 일은 중요하다. Retention에 배수로 작용할 수 있기 때문이다. Apple의 표현을 빌리면, 훌륭한 사용자 경험은 "그냥 된다".

게임을 자신의 관점에서 평가하려 애쓰는 것보다, 많은 사람을 대상으로 사용자 테스트를 진행하는 편이 훨씬 가치 있다. 모바일 게임에서 사람의 감정은 강력한 도구다. 뇌의 자연스러운 보상 경로와 조작적 조건화, 사회적 신호가 어떻게 작동하는지 이해하면 더 촘촘한 경험을 만들 수 있다.

UI/UX 디자인을 익히는 일은 버튼을 예쁘게 만드는 데서 끝나지 않는다. 오히려 게임 안에서 이용자가 겪는 경험 전부에 관한 문제다. 메커닉을 어떻게 효과적으로 전달할지, 그리고 게임이 어떻게 앞뒤가 맞게 느껴지도록 할지의 문제다.

거의 모든 개발자가 오랜 시간에 걸쳐 성공도 실패도 겪었을 것이다. 그래서 다음 주제와 관련된 "베스트" 링크 모음을 정리해 두었다.

- 터치스크린 조작

- UI 디자인

- 온보딩과 튜토리얼 디자인

- 플레이테스트와 사용성 테스트
