## 해석

이 글이 제시하는 틀은 3부 전체에서 가장 이식성이 높다. 두 동사의 차이를 정확히 잡는 것이 출발점이다.

| | 지우기 (Erasing) | 덜어 내기 (Easing) |
|---|---|---|
| 하는 일 | 부하를 아예 없앤다 | 부하의 크기를 줄인다 |
| 예 | 자동 발사, 콤보 삭제, 카드 원형 제거 | 감도 설정, 조작 커스터마이즈, 난이도 선택 |
| 대상 | 캐주얼 | 코어 |
| 위험 | 장르의 본질까지 지울 수 있다 | 설정이 많아 초보를 압도할 수 있다 |

CoD Mobile이 두 가지를 동시에 쓴 방식이 모범이다. 기본 조작은 지우기로 단순화하고, 고급 조작에서 25가지 이상의 항목을 열어 덜어 내기를 제공한다. **하나의 게임이 두 이용자층에게 다른 부하를 준다.** {{ch:golfclash-swing-success}}장의 위험 선호 분석과 구조가 같다. 집단을 나누고 각각에 다른 설정을 주는 것.

여기서 판단이 필요한 지점은 "무엇을 지우면 이 장르가 아니게 되는가"다. Marvel Snap은 덱 구성과 카드 원형, 개별 카드 공격까지 지웠는데도 CCG로 남았다. 지운 것이 많아 보이지만 **불확실성 아래에서의 선택**이라는 CCG의 본질은 남겨 두었기 때문이다.

## 사례

Marvel Snap의 결과가 이 틀의 효과를 수치로 보여 준다. 3~4분짜리 세션은 {{ch:creating-habit-forming-session-design}}장의 Starbucks Test를 통과하는 길이이며, 전통 CCG가 모바일에서 니치에 머물던 이유가 바로 세션 길이와 인지 부하였다.

IP에 대한 필자의 태도도 균형 잡혀 있다. Marvel이라는 IP가 오가닉 다운로드를 만들어 작은 스튜디오의 UA 전술이 되어 주지만, "IP만으로는 충분하지 않고 Retention과 플레이 편의, Core Loop의 고착도가 더 중요한 재료"라고 못 박는다. {{ch:crack-the-match-3-code-part-2}}장에서 같은 결론이 반복된다.

부하 감축의 원리는 하드코어 장르에만 쓰이는 것이 아니다. {{ch:adapting-games-for-mobile}}장 Rocket League SideSwipe는 3D를 2D로 바꾸고 참가 인원을 8명에서 6명으로 줄였다. 물리 연산과 화면 복잡도라는 두 부하를 동시에 지운 것이다. {{ch:how-stumble-guys-hit-225m-downloads}}장 Stumble Guys는 조작을 이동과 점프 둘로 지웠다.

반대 사례가 {{ch:vainglory-doesnt-make-one-will}}장이다. Vainglory는 PC MOBA의 부하를 거의 그대로 옮겼다. 20분 세션, 검지 두 개를 요구하는 조작, 방대한 챔피언 학습. 필자가 "모바일용 MOBA가 아니라 모바일에 올려놓은 MOBA"라고 표현한 그대로다.

## 적용 체크리스트

이식하려는 장르의 부하를 먼저 나열한다. 그다음 각 항목을 셋 중 하나로 분류한다.

| 부하 항목 | 지운다 | 덜어 낸다 | 남긴다 |
|---|---|---|---|
| 예: 정밀 조준 | 자동 조준 | 감도 설정 | |
| 예: 자원 관리 | | 단순화 | |
| 예: 세션 길이 | | 절반으로 | |

그리고 마지막으로 자문한다.

- 지운 항목을 모두 지웠을 때 이것은 여전히 그 장르인가
- 남긴 항목이 이 장르의 본질인가
- 코어 이용자를 위한 되돌리기 경로(고급 설정)가 있는가

세 번째가 없으면 캐주얼만 남고 장르 팬은 떠난다. CoD Mobile이 두 가지 기본 조작 옵션을 제공한 이유다.
