## 해석

{{ch:adapting-games-for-mobile}}장이 콘솔에서 모바일로 내려오는 이식을 다룬다면, 이 장은 모바일에서 VR로 올라가는 이식을 다룬다. 방향이 반대이므로 조정도 반대가 된다.

| | 콘솔 → 모바일 | 모바일 → VR |
|---|---|---|
| 조작 | 단순화 | 신체화 |
| 공간 | 축소 | 확장 |
| 세션 | 단축 | 유지 또는 연장 |
| 핵심 과제 | 부하 줄이기 | 공간을 쓸 이유 만들기 |

다섯 사례를 이 표로 읽으면 성패가 갈린 지점이 보인다. Fruit Ninja는 손가락 스와이프를 사무라이 검 두 자루로 바꿨다. 같은 동작이지만 신체가 개입하면서 감각이 달라졌다. Angry Birds는 새총을 실제로 당기게 하고 각도를 바꿔 볼 수 있게 했다. **평면에서 하던 일을 공간에서 하게 만든** 것이다.

반대로 Temple Run VR은 터치패드가 필요했고, 필자는 나중에 나온 Runaway VR이 "실제로 뛰고 좌우로 움직이는" 방식으로 그것을 개선했다고 평가한다. 이식은 했지만 **공간을 쓸 이유를 만들지 못한** 사례다.

## 사례

Space Team의 경우가 이식의 비용을 잘 보여 준다. 원래 카드 게임이었으므로 VR로 옮기려면 환경과 아바타, 조작을 전부 새로 만들어야 했다. 필자의 표현대로 "엄청난 작업"이었다. 여기서 이식이란 사실상 재제작에 가깝다.

Five Nights at Freddy's는 반대로 적은 조정으로 큰 효과를 얻은 사례다. 버튼을 누르려고 실제로 손을 뻗고, 패널과 문을 확인하려고 고개를 돌려야 한다. 원래 게임이 **제한된 시야와 대응 속도**를 다루고 있었기에 VR과 잘 맞았다. 장르가 매체를 만나면 조정이 적게 든다.

{{ch:cloudhead-games-advice-jumping-to-vr}}장과 함께 읽으면 이 장의 사례들이 왜 그렇게 갈렸는지가 설명된다. 그쪽에서 강조한 "환상의 실현"이라는 기준으로 보면, 검 두 자루를 쥔 Fruit Ninja와 터치패드를 쓰는 Temple Run VR의 차이가 분명해진다.

글 말미의 지적도 실무적이다. VR에서는 플레이어가 공간을 다르게 탐색하므로 **추적할 지표 자체가 달라진다.** 모바일에서 쓰던 시선 유도 기법이 통하지 않는 경우가 있다.

## 적용 체크리스트

| 점검 항목 | 확인할 것 |
|---|---|
| 신체화 | 기존 입력이 몸의 동작으로 바뀌면 더 좋아지는가 |
| 공간의 이유 | 3차원이 되어야만 성립하는 요소가 있는가 |
| 재제작 범위 | 환경·아바타·조작 중 새로 만들어야 하는 것은 |
| 장르 적합성 | 원작이 시야·반응·긴장을 다루는가 |
| 편안함 | 이동과 회전이 멀미를 유발하지 않는가 |
| 지표 | 기존 지표 중 무엇이 무의미해지는가 |

`공간의 이유`가 비어 있으면 이식하지 않는 편이 낫다. 평면에서 하던 일을 그대로 옮기면 조작만 불편해진다.
