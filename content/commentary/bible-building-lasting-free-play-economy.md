## 해석

원문은 인플레이션을 경제 디자이너의 적이라고 부르지만, 무엇이 망가지는지를 한 단계 더 파고들면 손댈 지점이 보인다. 재화가 흔해지면 사라지는 것은 돈의 가치가 아니라 **선택**이다.

```text
Balance(t+1) = Balance(t) + Source(t) − Sink(t)
```

이 식에서 Source가 Sink보다 꾸준히 크면 잔액이 계속 늘고, 잔액이 충분히 커지면 "무엇을 살까"라는 질문이 사라진다. 전부 살 수 있기 때문이다. 반대로 Sink가 지나치게 크면 아무것도 못 사서 역시 선택이 사라진다. 경제 설계의 목표는 균형 그 자체가 아니라 **플레이어가 매번 저울질하게 만드는 상태를 유지하는 것**이다.

그래서 경제를 점검할 때는 잔액 그래프보다 이 질문이 먼저다. 지금 이 플레이어가 가진 재화로 살 수 있는 것이 두 개 이상이고, 그중 하나만 고를 수 있는가.

원문이 나열한 Excel 함수 목록은 지루해 보이지만 요구하는 능력은 하나다. **가정을 넣으면 결과가 나오는 모델을 만들 수 있는가.** "평균 플레이어가 레벨업까지 전투를 몇 번 해야 하는가"에 답할 수 없다면, 그 게임의 진행 속도는 설계된 것이 아니라 우연이다.

## 사례

단일 재화 경제의 한계를 가장 선명하게 보여 주는 것이 {{ch:crack-the-match-3-code-part-2}}장의 Candy Crush 분석이다. 골드 바 하나로 굴러가는 구조 탓에 거의 모든 보상이 부스터로 수렴하고, 부스터는 일일 룰렛에서 공짜로 자주 들어오기 때문에 체감 가치가 희석된다. 이벤트를 열심히 해도 평소와 같은 것을 받으면 "그 노력이 무엇을 위한 것이었나"라는 질문이 남는다. 필자는 이것을 도파민 곡선의 하락으로 설명했다.

같은 글이 제시한 해법이 재화의 다층화와 희귀도다. {{ch:crack-the-match-3-code-part-2}}장의 Property Brothers는 일반 코인과 **기간 한정 토큰**을 분리해, 이벤트 참여가 평상시 진행에도 이득이 되도록 만들었다. 재화를 하나 더 만든 것이 아니라 재화의 용도를 분리해 선택지를 늘린 사례다.

희귀도가 만든 정체성의 예로 원문 밖에서 자주 인용되는 것이 Angry Birds의 Mighty Eagle이다. {{ch:crack-the-match-3-code-part-2}}장이 이것을 CCS의 부스터와 대비시킨 이유는 성능이 아니라 **획득 빈도**에 있다. 같은 아이템이라도 자주 주면 배경이 되고, 드물게 주면 사건이 된다.

## 적용 체크리스트

재화별로 한 줄씩 채운다. 칸이 비면 그 재화는 아직 설계되지 않은 것이다.

| 재화 | Source (획득처) | Sink (소비처) | 상한 | 이 재화만의 용도 |
|---|---|---|---|---|
| 소프트 | | | | |
| 프리미엄 | | | | |
| 이벤트 전용 | | | | |
| 소모품 | | | | |

그다음 아래 세 가지를 모델로 확인한다.

- 무과금 플레이어의 30일 잔액 곡선이 우상향으로 발산하는가
- 각 재화의 최대 Sink가 최대 Source보다 큰가
- 지금 잔액으로 살 수 있는 선택지가 항상 둘 이상인가

세 번째가 이 장에서 가져갈 가장 중요한 기준이다. 잔액이 아니라 **선택의 존재**가 경제의 건강을 말해 준다.
